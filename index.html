☁️ Firebase 클라우드 연결

Firebase에 연결하면 모든 데이터가 클라우드에 자동 저장됩니다. 다른 기기에서도 같은 데이터로 복구됩니다. (localStorage + Firebase 이중 보존)

📘 Firebase 설정 가이드

  1. Firebase Console → 프로젝트 추가 (이름 예: production-erp)
  2. 빌드 → Firestore Database → 데이터베이스 만들기 → 위치 asia-northeast3(서울) → 테스트 모드로 시작
  3. 프로젝트 설정(⚙️) → 내 앱 → 웹 앱(</>) 추가 → firebaseConfig 객체 복사
  4. 복사한 firebaseConfig를 위 입력란에 붙여넣고 연결 & 저장
  5. Authentication → 로그인 방법 → 익명 사용 설정 (보안규칙 대응)
  6. Firestore 규칙을 아래로 설정: 
    rules_version = '2';
service cloud.firestore {
  match /databases/{db}/documents {
    match /{doc=**} {
      allow read, write: if request.auth != null;
    }
  }
}
